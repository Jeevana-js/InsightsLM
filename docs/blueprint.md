# **App Name**: Class 10 Tutor

## Core Features:

- Subject Selection: Display subject options for Class 10.
- Textbook Display: Show official textbooks for the selected subject.
- AI Tutor: Provide an AI tutor interface to ask questions related to the selected textbook, answering only using information present in the text. Use an LLM tool for extracting specific facts or explanations from the official textbook.
- Quiz Generation: Generate a quiz from the content of the official textbook, leveraging an LLM tool to assess relevancy.

## Style Guidelines:

- Primary color: A calm blue (#64B5F6) to inspire confidence and focus.
- Background color: A light, desaturated blue (#E3F2FD) to provide a gentle backdrop.
- Accent color: A vibrant yellow (#FFCA28) to highlight interactive elements.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text.
- Use clear, simple icons to represent different subjects and sections within the app.
- Maintain a clean and organized layout to ensure easy navigation and readability.
- Incorporate subtle animations, such as page transitions, to enhance user engagement.
